# Bank Loan Management System

This is a simple Flask-based Bank Loan Management System that allows:
- Creating loans for customers
- Making payments (EMI or lump sum)
- Viewing loan ledger and account overview

## Features

- LEND: Issue loan to customer with interest
- PAYMENT: Make EMI or lump sum payment
- LEDGER: View full loan transaction history
- ACCOUNT OVERVIEW: Summary of all loans taken by a customer

## Tech Stack
- Python
- Flask
- SQLite

## How to Run

```bash
python app.py
